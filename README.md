## 🚀 Key Features

- **Responsive Design:** Optimized for mobile phones, tablets, laptops, and wide desktop screens.
- **Theme Switching:** Dark mode and light mode with automatic system detection and local persistence.
- **Fluid Animations:** Scroll-triggered reveals, spring layout transitions, and micro-interactions powered by `motion`.
- **Categorized Technical Skills:** Interactive live search and categorical filtering for Web Dev, Programming, Database, Tools, and Core Concepts.
- **Projects Showcase:** Detailed cards and modal dialogs for Machine Learning and Web Engineering projects with honest status badges.
- **Education Timeline:** Chronological milestone progression from SSLC and PUC to B.E. in Computer Science & Design.
- **Accreditations & Activities:** Highlighting verified coursework, NSS leadership, and technical hackathon involvement.
- **Direct Contact:** Client-side validated inquiry form, direct email dispatch, and one-click contact details copying.

## 💻 Local Development Setup

Clone the repository and install dependencies:

```bash
# Clone the repository
git clone https://github.com/neelambikamatagar/portfolio.git

# Navigate to directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be running locally at `http://localhost:3000` (or `http://localhost:5173` depending on your local port configuration).

### Build for Production

```bash
npm run build
```

The production-ready static assets will be output to the `dist/` directory.
